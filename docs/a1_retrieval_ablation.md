# A1 retrieval ablation (Sprint 1)

5 retrievers compared on MS Marco v2.1 validation subset (n=30 queries, top_k=10).

Source: `eval_results/retrieval_ablation.json` (generated by `scripts/run_retrieval_ablation.py`).

## Results

| Method | MRR@10 | NDCG@10 | Lift over dense |
|---|---:|---:|---:|
| bm25 | 0.3723 | 0.5207 | -0.172 |
| dense (BGE-M3 cosine) | **0.5448** | 0.6568 | (baseline) |
| hybrid_rrf (BM25 + dense, k=60) | 0.5374 | 0.6492 | -0.007 |
| dense + Cohere rerank-v3.5 | **0.6456** | **0.7334** | **+0.101** |
| hybrid_rrf + Cohere rerank-v3.5 | 0.6456 | 0.7334 | +0.101 |

## Interpretation

- **Dense alone beats BM25 by ~17 MRR points.** Expected for semantic similarity on factoid queries where exact-keyword overlap is weak.
- **Hybrid RRF does not help.** On this MS Marco subset, BM25 adds noisier candidates that dilute dense's strong rank. RRF assumes both retrievers contribute orthogonal signal; when one is much weaker, fusion is at best neutral.
- **Reranker is the big win: +10 MRR points.** Cohere rerank-v3.5 is a cross-encoder, so it can score query-doc relevance more precisely than bi-encoder similarity. Worth the ~0.5s latency hit per query.
- **Hybrid + rerank ≡ dense + rerank.** Within top_k=10, both converge because the reranker corrects for the upstream's choice of shortlist.

## Production choice

**Ship dense (BGE-M3) → Cohere rerank-v3.5 as the standard retrieval stack**, drop hybrid_rrf as v4 production scope:
- No fusion-tuning cost (RRF on this corpus is a wash, no improvement to justify the maintenance).
- Cohere free trial 1000 calls/month is sufficient for the agent's expected demo traffic.
- BM25 path preserved in `src/retrieval/methods.py` for future ablations and as a sanity baseline.

## Caveats

- **n=30 is small.** MRR variance is non-trivial; expect ±0.03 swing across resamplings.
- **MS Marco is factoid retrieval.** For the enterprise agent's actual workload (cross-source briefings on synthetic enterprise data), the hybrid story may flip — keep BM25 + RRF available as a code path for future evaluation.
- **rank_bm25 default parameters.** k1=1.5, b=0.75. No corpus-specific tuning.
- **Cohere trial rate limit.** 10 calls/minute throttle applied in code; production key would remove this for high-throughput evaluation.
